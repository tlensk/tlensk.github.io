# Tatiana Lenskaia — Academic CV Website

Revised static academic CV / research portfolio.

## Structure

- `index.html` — research identity homepage
- `work.html` — research and teaching timeline
- `pubs.html` — journal articles and conference publications
- `talks.html` — talks, workshops, advisory meetings, and conference presentations
- `edu.html` — education and thesis work
- `assets/css/style.css` — shared site styling
- `assets/js/main.js` — small script for dynamic copyright year
- `assets/img/` — profile image
- `assets/pdf/` and `assets/data/` — supporting files linked from the site

## Design direction

The redesign removes the generic Bootstrap look and replaces it with a restrained academic/research visual system: warm paper background, monochrome portrait treatment, grid texture, serif headings, cards, timelines, and structured publication entries.

## Bright theme update

This version uses a brighter “Bright Biomedical Notebook” visual direction: warm ivory background, soft green/yellow/blue accents, pill navigation, rounded cards, and a research-theme hero visual instead of a circular portrait. The portrait file remains in `assets/img/` in case a rectangular portrait card is desired later.
